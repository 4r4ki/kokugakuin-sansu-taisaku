# 算数マスター（中学入試・算数対策）

中学入試によく出る「濃度（食塩水）」の問題と、角度・面積・特殊算・速さなどの難問を、ヒントと解き方の解説つきで練習できるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。
GitHub Pages を有効にすれば、スマホやタブレットからも使えます。

- 問題を解いて答えを入力 →「答え合わせ」
- わからないときは「ヒント」を1つずつ表示
- 「解き方の解説」はステップごとに表示（天びん図・表つき）
- 正解した問題は記録されます（ブラウザに保存）
- 画面上の「濃度マスター」と「難問チャレンジ」でコーナーを切りかえ（難問はオレンジ色で表示）
- 「難問チャレンジ」で、12分野の難問108問に挑戦（図形の問題は図つき）
- 答えが分数のときは「3/11」や帯分数「16と4/11」で入力できます
- 「練習（自動）」タブで、数字が毎回かわる練習問題に何回でも挑戦（正解数・連続正解を記録）
- 「解き方のコツ」タブで公式・天びん図・考え方を確認

## 収録問題（30問）

| 分野 | 内容 |
| --- | --- |
| まぜる | 天びん図の基本、混ぜる量、量を逆にした、3種類を混ぜる、何%を混ぜた、比で混ぜる3種類、混ぜる比を逆に、同じ重さ＋水 |
| 蒸発・水を加える | 水の蒸発、水を2回加える、水に移してうすめる、水でうすめて作る、濃度が1.25倍に |
| 食塩を加える | 食塩を加える量、もとの量を求める、蒸発させてから食塩を加える、食塩と水の比 |
| やりとり | A・B間のやりとり、くみ出して水を入れる、何回目で○%以下、同じ量を交換、何g移した、3つの容器のリレー、水と行ったり来たり |
| 逆算・消去算 | 混ぜ方を変えた2通り、水を混ぜた消去算、水を入れすぎた、水とくらべる、予定より少なく入れた |
| 時間とともに | 毎分入れ続ける |

## 練習問題（自動生成）

`js/generator.js` が、答えがきれいな数になるように数字を選んで問題を作ります。解説も同じ数字で自動で作られます。

混ぜた濃度／混ぜる量／水の蒸発／水でうすめる／食塩を加える／AとBのやりとり／くみ出しのくり返し／消去算／同じ量を交換（9種類）

## バージョン管理

変更履歴は [CHANGELOG.md](CHANGELOG.md) にまとめています。リリースごとに `v2.0.0` のような Git タグをつけています。

新しいバージョンを出すときは、次の作業をします。

1. `CHANGELOG.md` に変更内容を書く
2. `index.html` のバージョン表示と、`?v=…`（ファイルの読みこみ）の番号を新しいバージョンに変える
3. コミットして、`git tag -a vX.Y.Z -m "…"` でタグをつけ、`git push --follow-tags` する

## 問題の追加

`js/problems.js` の `PROBLEMS` に同じ形式で追加してください。
解説の図は `fig` に `tenbin`（天びん図）または `table`（表）を指定できます。
